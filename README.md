## 파일 구성

| 파일 | 수정하는 내용 |
| --- | --- |
| `content.js` | **작품명·분류·설명·사진·영상 목록, 첫 화면 사진** (관리자 모드가 이 파일을 만들어 줍니다) |
| `index.html` | 첫 화면, 상단 메뉴, Contact 등 기본 구성 |

| `backgrounds/` | 첫 화면 격자 뒤에 넣을 원본 사진 |
| `media/` | 관리자 모드에서 새로 올린 사진·영상이 들어가는 곳 |
| 기존 이미지·영상 파일 | 작품 원본과 대표 이미지 |

## 관리자 모드로 빠르게 수정하기

사이트를 열어 둔 상태에서 **숫자 `1` 을 빠르게 다섯 번** 누르면 오른쪽에 관리자 패널이 열립니다.
(글자를 입력하는 칸에 커서가 있을 때는 열리지 않습니다. `Esc` 로 닫고, 다시 연타하면 또 열립니다.)

패널에서 할 수 있는 일:

- 작품 제목 · 분류 · 설명 고치기 — 입력하는 즉시 뒤쪽 화면에 반영됩니다
- 대표 이미지(그리드 썸네일)와 상세창의 사진·영상 **갈아끼우기**
- 상세창 미디어 추가 · 삭제 · 순서 바꾸기
- 작품 순서 바꾸기, 작품 추가 · 삭제 (번호는 자동으로 다시 매겨집니다)
- 커버 배경색 고르기
- 첫 화면의 이름과 배경 사진 바꾸기
- `되돌리기` 로 직전 수정 취소

### 수정한 내용을 실제 사이트에 올리기

관리자 모드의 수정은 **내 브라우저에만 임시 저장**됩니다. 실제 사이트에 올리려면:

1. 패널 오른쪽 위 **`내보내기`** 를 누르면 zip 파일을 받습니다.
2. 압축을 풀면 `content.js` 와 (새 사진·영상이 있으면) `media/` 폴더가 나옵니다.
3. 두 가지를 이 프로젝트 폴더에 그대로 덮어씁니다.
4. 사이트를 새로고침해 확인한 뒤, 패널의 `임시 저장 지우기` 를 눌러 브라우저 임시본을 정리합니다.
5. 커밋·푸시합니다.

```sh
git add content.js media
git commit -m "포트폴리오 내용 수정"
git push
```

`임시 저장 지우기` 를 누르면 언제든 `content.js` 에 저장된 내용으로 되돌아갑니다.

> 관리자 모드는 로그인 없이 누구나 열 수 있지만, 고친 내용은 그 사람의 브라우저에만 남고
> 실제 사이트 파일은 바뀌지 않습니다. 사이트를 바꾸려면 위처럼 파일을 커밋·푸시해야 합니다.
>
> 브라우저에 사진을 임시 보관하려면 IndexedDB 와 localStorage 가 필요합니다.
> `index.html` 을 파일로 직접 여는 대신 아래의 로컬 서버나 배포된 주소에서 사용하세요.

## 첫 화면 사진 넣기

1. 새 사진을 `backgrounds/` 폴더에 JPG, PNG 또는 WebP로 저장합니다.
2. `content.js`의 `hero.image` 와 `index.html`의 이미지 preload 경로를 새 파일 경로로 바꿉니다. 현재 경로는 `backgrounds/hero.webp`입니다.
   (관리자 모드의 `첫 화면 배경 사진` 에서 골라도 됩니다. 이때 preload 경로만 직접 맞춰 주세요.)
3. 브라우저를 새로고침합니다.

격자는 사진 위에 자동으로 적용되므로 사진에 격자를 미리 그릴 필요가 없습니다. 사진 위치는 `portfolio.css`의 `.hero-mosaic`에서 조정합니다. 상세한 설정은 `backgrounds/README.md`를 참고하세요.

## VS Code에서 수정하기

VS Code의 **파일 → 폴더 열기**에서 이 폴더를 선택합니다. 메인 화면은 `index.html`입니다. 별도의 패키지 설치나 빌드가 필요하지 않습니다.

`index.html`을 브라우저로 열거나, 이 폴더에서 로컬 웹 서버를 실행해 확인할 수 있습니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저 주소: http://127.0.0.1:8000/

기본 첫 화면과 그리드는 외부 폰트·라이브러리 없이 동작합니다. 운영체제의 동작 줄이기 설정을 존중합니다. 영상은 기존 MOV 파일을 사용하므로 재생 가능 여부는 브라우저의 코덱 지원에 따라 달라집니다.
