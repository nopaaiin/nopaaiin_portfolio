# nopaaiin — 뽁뽁이 (Bubble Wrap)

Interactive Design (2) 과제 단독 아카이브. nopaaiin_portfolio의 Interactive Design (2) 아카이브와 같은 레이아웃에서 첫 화면(배경 격자 이미지)만 뺀 구성입니다.

| 파일 | 내용 |
| --- | --- |
| `index.html` | 상단 메뉴, 작품 그리드, Contact |
| `content.js` | 작품명, 분류, 설명, 대표 이미지 |
| `portfolio.css`, `portfolio.js` | 기존 아카이브와 같은 스타일과 코드 (첫 화면 없이 동작하도록 수정, `embed` 타입 추가) |
| `bubblewrap/index.html` | 뽁뽁이 인터랙션 본체 (폰 전체 화면용) |
| `bubblewrap-cover.png` | 대표 이미지 |
